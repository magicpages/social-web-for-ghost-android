# Security

Please report security problems privately, not in a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/magicpages/social-web-for-ghost-android/security/advisories/new) for this repository. Include the app version (Settings → About), the Android version, and the steps to reproduce.

You'll get a reply within a few working days. Once a fix is out on Google Play, the advisory is published with credit to you, unless you'd rather stay anonymous.

Fixes go into the latest version only.
